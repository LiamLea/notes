### Overview

#### 1.Basic Concepts

##### (1) Clock Speed 
How many cycles (ticks) a CPU core executes per second

* if this is too low, in single thread, task B will waiting longer to run when task A is running

##### (2) IPC (Instructions Per Cycle)
the average real-world IPC typically ranges between 1.5 and 4.0 instructions per cycle

##### (3) Throughput (MIPS / FLOPS)

The total volume of mathematical or logical operations completed per second.
